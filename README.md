# Portfolio — Mamadou NDIAYE

Portfolio professionnel one-page · FullStack Engineer & SaaS Builder · Dakar, Sénégal

🌐 [mamadoundiaye-dev-fullstack.netlify.app](https://mamadoundiaye-dev-fullstack.netlify.app)

## Stack

- [Astro](https://astro.build) + [Tailwind CSS v4](https://tailwindcss.com)
- Déploiement : [Netlify](https://netlify.com) (statique)
- Formulaire : Netlify Forms

## Développement local

```bash
npm install
npm run dev
```

## Déploiement

Chaque push sur `main` déclenche un redéploiement automatique sur Netlify.
